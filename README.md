# Fonts

Typefaces drawn for [divi-nation](https://github.com/divi-nation) projects, free to

| Font | What it is | Preview |
| :--- | :--- | :--- |
| [Chockabloque](Chockabloque/) | Block display capitals — solid slabs, 45° bites, V-notches, counters shrunk to thin slits. A–Z, 0–9 and common punctuation; lowercase shows the capitals. | [preview](https://divi-nation.github.io/fonts/Chockabloque/chockabloque-preview.html) |

## Using one on a web page

Each font's folder holds a `.woff2` and a stylesheet. Link the stylesheet
straight from here:

    <link rel="stylesheet" href="https://divi-nation.github.io/fonts/Chockabloque/chockabloque.css">
    <style> h1 { font-family: "Chockabloque", sans-serif; } </style>

or copy the two files beside your page and link them locally. To install a font on
a computer, use its `.ttf`.
